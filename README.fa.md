# pTp — عبارت به پلی‌لیست

یک عبارت مثل *«صبح یکشنبه بارانی، قهوه گرم، هیچ برنامه‌ای ندارم»* بنویسید و در عوض یک پلی‌لیست بگیرید: یک عنوان، یک توضیح کوتاه و آهنگ‌های واقعی — هر کدام با نام خواننده و یک جمله که چرا به این حس می‌خورد. هر آهنگ به جست‌وجوی Spotify و YouTube لینک دارد و داخل خود برنامه می‌توانید پیش‌نمایش ۳۰ ثانیه‌ای آن را پخش کنید.

با هر سرویس سازگار با OpenAI (از جمله سرویس‌های رایگان) کار می‌کند، کاملاً روی سیستم خودتان اجرا می‌شود و هیچ وابستگی (dependency) ندارد.

## شروع سریع

**گزینه ۱ — دانلود (ویندوز)**

1. فایل `PhraseToPlaylistDesktop.exe` (پنجره مستقل، بدون کنسول) یا `PhraseToPlaylist.exe` (کنسول + مرورگر) را از [Releases](https://github.com/3000S-HTTP/pTp/releases) دانلود کنید.
2. اجرا کنید؛ مرورگر خودبه‌خود باز می‌شود.

**گزینه ۲ — اجرا از کد (هر سیستم‌عاملی)**

```bash
python server.py
```

کنسول آدرس دقیق را چاپ می‌کند — معمولاً `http://localhost:8000/playlist.html`. فقط Python 3 لازم است؛ سرور فقط از کتابخانه استاندارد پایتون استفاده می‌کند.

**در هر دو حالت:**

1. **AI Settings** را باز کنید و حداقل یک کلید API وارد کنید. **API base URL** را روی `/proxy` بگذارید، مگر اینکه دقیقاً بدانید چه چیز دیگری لازم دارید.
2. یک عبارت بنویسید و **Generate playlist** را بزنید.

## امکانات

- **پلی‌لیست از یک عبارت** — یک حس یا لحظه تبدیل به پلی‌لیستی با عنوان، توضیح، آهنگ‌های واقعی، نام خواننده و دلیل کوتاهی برای هر انتخاب می‌شود.
- **هر سرویس سازگار با OpenAI** — شامل OpenAI، Groq، OpenRouter، Google Gemini، Together، Ollama، LM Studio، tokenharbor و غیره (بخش «تنظیمات»).
- **چند کلید API با جایگزین خودکار** — کلیدها به‌ترتیب امتحان می‌شوند و اگر کلید نامعتبر بود، به سقف نرخ برخوردید یا سرور خطا داد، برنامه خودکار سراغ کلید بعدی می‌رود.
- **پیش‌نمایش ۳۰ ثانیه‌ای** — کنار هر آهنگ دکمه ▶ هست که قطعه‌ای ۳۰ ثانیه‌ای پخش می‌کند و بر اساس نام آهنگ و خواننده پیدا می‌شود، پس هیچ‌وقت آهنگ اشتباه پخش نمی‌کند.
- **پوسته‌های قابل نصب** — Monochrome، Liquid Glass، Ocean، Sunset و Neon، هر کدام با حالت روشن و تیره.
- **روی موبایل هم کار می‌کند** — سرور یک آدرس داخل شبکه چاپ می‌کند که با هر دستگاه روی همان وای‌فای باز می‌شود.
- **همه‌جا اجرا می‌شود** — یک فایل پایتون بدون وابستگی، یا فایل اجرایی ویندوز (نسخه کنسول یا نسخه دسکتاپ).
- **مقاوم در برابر خروجی نامرتب مدل‌ها** — پروکسی CORS داخلی برای سرویس‌هایی که به مرورگر اجازه دسترسی نمی‌دهند، و پارسر JSON منعطفی که کوتیشن مارک‌داون، آپاستروف، کلید بدون نقل‌قول، ویرگول انتهایی، آبجکت دربرنده و لیست ساده آهنگ را هم می‌فهمد.

## تنظیمات

در برنامه، **AI Settings** را باز کنید:

| فیلد | چه چیزی وارد کنید |
| --- | --- |
| **API keys** | یک یا چند کلید از سرویس دلخواهتان. فقط در همین مرورگر ذخیره می‌شود (`localStorage`) و هرگز به سرور نمی‌رود. هر سطر چک‌باکس فعال/غیرفعال، Show/Hide و Delete دارد. |
| **API base URL** | `/proxy` (پیش‌فرض) از پروکسی داخلی رد می‌شود و همان باعث می‌شود سرویس‌ها در Safari، Chrome و مرورگرهای موبایل کار کنند. آدرس کامل مثل `https://api.openai.com/v1` فقط وقتی بگذارید که آن سرویس به درخواست مرورگر (CORS) اجازه بدهد. |
| **Model** | نام مدلی که سرویس شما انتظار دارد. |

کلید شما فقط در همان درخواستی که به سرویس دلخواهتان می‌رود فرستاده می‌شود. نه آنالیتیکسی در کار است و نه بک‌اند دیگری.

## پوسته‌ها

در پابرجم روی **Themes ▸** بزنید تا مدیر پوسته‌ها باز شود.

- **نصب** — در بخش *Browse themes* روی **Install** بزنید. کارت به *Your themes* منتقل و همان لحظه اعمال می‌شود.
- **تعویض** — روی کارت موردنظر در *Your themes* بزنید. کارت فعال کادر دارد.
- **حذف** — روی **Uninstall** بزنید. اگر پوسته فعال را حذف کنید، به پوسته پیش‌فرض Monochrome برمی‌گردید که همیشه نصب است و حذف نمی‌شود.
- **روشن / تیره** — روی **Dark / Light** در پابرجم بزنید. هر پوسته هر دو حالت را دارد.

| پوسته | ظاهرش |
| --- | --- |
| Monochrome | همان سیاه‌وسفید اصلی — پیش‌فرض، همیشه نصب است |
| Liquid Glass | پنل‌های شیشه‌ای مات روی گرادیان بنفش تا نیلی |
| Ocean | گرادیان سبزآبی تا سرمه‌ای، آبیِ اعماق دریا |
| Sunset | گرادیان نارنجی تا بنفش با رنگ‌های گرم غروب |
| Neon | حالت روشن پاستلی و حالت تیره تقریباً مشکی، با هاله صورتی و فیروزه‌ای |

پوسته‌های نصب‌شده و پوسته فعال در همین مرورگر ذخیره می‌شوند (`localStorage`، کلید `phrase-playlist-themes-v1`) و چیزی به سرور نمی‌رود.

## پیش‌نمایش آهنگ

کنار هر ردیف آهنگ دکمه **▶ Preview** هست که قطعه‌ای ۳۰ ثانیه‌ای پخش می‌کند:

1. در [iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/) اپل (عمومی و بدون کلید) دنبال «نام آهنگ + خواننده» می‌گردد — از داخل مرورگر و بدون هیچ کلید API.
2. نتایج با مقایسه عنوان و خواننده امتیاز می‌گیرند؛ فقط امتیاز ۰٫۵۵ به بالا پخش می‌شود، وگرنه پیام *No preview found* نشان داده می‌شود تا آهنگ اشتباه پخش نشود.
3. یک پخش‌کننده مشترک: دوباره بزنید تا مکث کند، و باز بزنید تا ادامه دهد. با ساخت پلی‌لیست جدید، پخش متوقف می‌شود.

هر جست‌وجو بعد از اولین کلیک کش می‌شود؛ پس پخش دوباره فوری است و درخواست اضافه نمی‌فرستد. پیش‌نمایش به اینترنت نیاز دارد، ولی لینک‌های Spotify و YouTube همیشه کار می‌کنند.

## استفاده در آیفون

1. سرور را روی کامپیوترتان اجرا کنید (فایل اجرایی یا `python server.py`).
2. کامپیوتر و گوشی باید **به یک شبکه** (یک وای‌فای) وصل باشند.
3. در کنسول، آدرس «Phone / tablet» را پیدا کنید، مثلاً `http://192.168.1.100:8000/playlist.html`.
4. در Safari باز کنید، بعد Share → **Add to Home Screen** تا آیکونی مثل اپ پیدا کنید.
5. اگر باز نشد، به برنامه اجازه فایروال بدهید یا بررسی کنید هر دو در یک شبکه باشند — VPN و آداپتورهای Hyper-V معمولاً دردسرسازند.

## میزبانی ۲۴ ساعته

خود برنامه رایگان است؛ فقط سرویس AI ممکن است هزینه داشته باشد:

- **محلی و برای همیشه رایگان** — [Ollama](https://ollama.com) را نصب کنید، Base URL را روی `http://localhost:11434/v1` بگذارید و هر کلید بی‌معنی‌ای وارد کنید. بدون اینترنت، بدون هزینه و بدون محدودیت نرخ — فقط کامپیوترتان باید روشن باشد.
- **طرح‌های رایگان API** — Google Gemini و Groq طرح‌های رایگان جذابی دارند و OpenRouter مدل‌هایی با پسوند `:free` دارد. طرح‌های رایگان سقف نرخ دارند و ممکن است تغییر کنند؛ پس آن‌ها را «بهترین تلاش» حساب کنید، نه ظرفیتِ تضمین‌شده.
- **میزبانی رایگان** — `server.py` را روی Railway، Render، Fly.io یا Cloudflare Workers (طرح‌های رایگان خوابند یا سهمیه دارند) مستقر کنید، یا روی یک کامپیوتر خانگی یا Raspberry Pi نگهش دارید و Base URL را به سرویسی با طرح رایگان وصل کنید.

چیزی به‌عنوان هوش مصنوعی کاملاً رایگان، نامحدود و تضمینی ۲۴ ساعته وجود ندارد. نزدیک‌ترین حالت: **Ollama محلی + همین برنامه روی دستگاهی که روشن می‌ماند**.

### استقرار روی Railway

برنامه یک فایل پایتون واحد و بدون وابستگی است، پس همان‌طور که هست مستقر می‌شود: Railway متغیر `PORT` را ست می‌کند، سرور از آن استفاده می‌کند، روی `0.0.0.0` bind می‌کند، در حالت میزبانی باز کردن خودکار مرورگر را خاموش می‌کند و `GET /healthz` دارد.

1. مخزن را در GitHub پوش کنید.
2. در [railway.app](https://railway.app) به **New Project** → **Deploy from GitHub repo** بروید و مخزن را انتخاب کنید.
3. اگر ریشه پروژه (root directory) خواست، `U` را بگذارید — پوشه‌ای که `server.py` داخل آن است.
4. فایل‌های `Procfile` و `railway.json` دستور اجرا (`python server.py`) و چک سلامت (`/healthz`) را می‌دهند؛ Railway خودش پایتون را تشخیص می‌دهد.
5. آدرس ساخته‌شده (`https://<your-app>.up.railway.app`) را باز کنید — به `playlist.html` هدایت می‌شود.
6. کلیدتان را در **AI Settings** بگذارید و Base URL را روی `/proxy` نگه دارید.

متغیرهای اختیاری (Railway → Variables):

| متغیر | کاربرد |
| --- | --- |
| `UPSTREAM_BASE` | تغییر سرویس بالادستی پیش‌فرض، مثلاً `https://api.openai.com/v1`. |
| `NO_BROWSER` | مقدار `1` باعث می‌شود مرورگر هرگز خودکار باز نشود (در حالت میزبانی خودکار است). |

نکته‌ها درباره میزبانی:

- سایت عمومی است — هرکسی با آدرس می‌تواند رابط کاربری را باز کند. کلیدها در `localStorage` هر بازدیدکننده می‌ماند و سمت سرور ذخیره نمی‌شود، پس کسی کلید شما را نمی‌بیند؛ هرچند پروکسی هر کلیدی که بازدیدکننده بفرستد را جلو می‌برد.
- اعتبار آزمایشی Railway تمام می‌شود و سرویسِ همیشه‌روشن به طرح پولی نیاز دارد. برای همیشه‌روشنِ رایگان، برنامه را روی دستگاه خودتان اجرا کنید.

## ساخت فایل‌های اجرایی

این دستورها را داخل پوشه `U/` اجرا کنید؛ هر دو در `U/dist/` ساخته می‌شوند.

**نسخه کنسول/سرور** — سرور محلی را اجرا و مرورگر پیش‌فرض را باز می‌کند:

```bash
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --name "PhraseToPlaylist" --add-data "playlist.html;." --console server.py
```

**نسخه دسکتاپ** — در پنجره مخصوص خودش باز می‌شود، نه در تب مرورگر، و خبری از پنجره کنسول نیست:

```bash
python -m pip install pyinstaller pywebview pythonnet
python -m PyInstaller --noconfirm --onefile --windowed --name "PhraseToPlaylistDesktop" --add-data "playlist.html;." --hidden-import server --collect-all webview --collect-all pythonnet --collect-all clr_loader desktop/app.py
```

نسخه دسکتاپ با `desktop/app.py` رابط کاربری را داخل **WebView2** (اجرای Edge Chromium) از طریق pywebview جاسازی می‌کند. فقط ویندوز ۱۰/۱۱؛ WebView2 روی ویندوزهای امروزی نصب است — اگر پنجره خالی بود، WebView2 Runtime را از مایکروسافت نصب کنید.

## عیب‌یابی

| مشکل | راه‌حل |
| --- | --- |
| `Failed to fetch` | فایل را مستقیم باز کردید (`file://`). `python server.py` یا فایل اجرایی را اجرا کنید و از آدرس `http://localhost:...` که چاپ می‌کند استفاده کنید. |
| `Failed to fetch` با آدرس مستقیم سرویس | آن سرویس به درخواست مرورگر (CORS) اجازه نمی‌دهد. Base URL پیش‌فرض یعنی `/proxy` را بگذارید. |
| `401` / رد شدن کلید | کلید نامعتبر یا غیرفعال است. نزد سرویس‌دهنده تعویضش کنید یا در **AI Settings** دوباره فعالش کنید. |
| خطای پروکسی `502` | خطای موقت سرویس بالادستی — پروکسی سه بار تلاش می‌کند. دوباره امتحان کنید یا کلید را عوض کنید. |
| `Could not parse ... JSON` | پنل **Raw model response** خروجی خام را نشان می‌دهد؛ اگر تکرار شد، مدل دیگری که دستور JSON را بهتر رعایت کند انتخاب کنید. |
| دکمه **▶ Preview** می‌گوید *No preview found* | آهنگ در کاتالوگ iTunes نیست یا عنوان/خواننده خیلی فرق داشته. لینک‌های Spotify و YouTube همچنان کار می‌کنند. |
| پوسته نصب‌شده ناپدید شد | پوسته‌ها در `localStorage` ذخیره می‌شوند؛ پاک کردن داده‌های سایت آن‌ها را حذف می‌کند. از *Browse themes* دوباره نصب کنید. |
